CodeNote 개인정보 처리방침

최종 수정: 2026년 9월 3일

CodeNote는 개인정보를 수집하지 않습니다. 앱이 스스로 사용자 데이터를 외부로 전송하는 기능이 없습니다.

기기에만 저장되는 것

다음은 전부 기기 내부(앱 전용 저장 영역)에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

  • 손으로 쓴 노트의 필기 데이터
  • 인식된 파이썬 코드 및 LaTeX 수식
  • 코드 실행 결과와 생성된 그래프 이미지
  • 노트 이름, 생성·수정 시각, 결과 패널 위치 같은 앱 설정

앱을 삭제하면 이 데이터도 함께 삭제됩니다.

손글씨 인식

손글씨 인식은 전적으로 기기 안에서 이루어집니다. 인식 모델은 앱에 포함되어 배포되며, 인식을 위해 필기나 이미지를 서버로 보내지 않습니다. 인식 기능을 쓰기 위한 다운로드나 계정 로그인도 필요하지 않습니다.

네트워크 사용

앱 자체는 네트워크에 접속하지 않습니다. 다만 이 앱은 사용자가 작성한 파이썬 코드를 실행하는 것이 목적이므로, 사용자가 직접 작성한 코드가 네트워크에 접속할 수 있습니다. 예를 들어 requests 라이브러리로 웹 API를 호출하는 코드를 작성해 실행하면, 그 통신은 사용자가 지정한 서버와 직접 이루어집니다. 이 통신의 내용은 개발자에게 전달되지 않으며 개발자가 관여하지 않습니다. 앱에 포함된 예시 노트 중 하나가 이런 코드를 보여주기 위해 공개 API를 호출합니다.

문제 신고

앱의 “Report a Problem” 메뉴는 사용자가 직접 보낼 때만 동작합니다. 시스템 메일 또는 공유 시트가 열리고, 사용자가 내용을 확인한 뒤 보낼지 결정합니다. 자동으로 전송되는 것은 없습니다.

첨부되는 진단 파일에는 다음이 들어갑니다.

  • 앱 버전, iOS 버전, 기기 모델명
  • 현재 노트의 이름과 코드, 마지막 실행 출력
  • 최근 앱 동작 기록(실행 성공/실패 등)

보내기 전에 내용을 직접 확인하고 수정하거나 취소할 수 있습니다.

추적 및 제3자 제공

  • 광고 식별자를 사용하지 않으며, 사용자를 추적하지 않습니다.
  • 분석·광고 SDK를 포함하지 않습니다.
  • 수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다.

아동의 개인정보

수집하는 개인정보가 없으므로, 연령과 무관하게 수집되는 정보가 없습니다.

변경 고지

이 방침이 바뀌면 이 페이지를 갱신하고 상단의 최종 수정일을 변경합니다.

CodeNote Privacy Policy

Last updated: September 3, 2026

CodeNote does not collect any personal data. The app has no capability to transmit your data anywhere.

Stored only on your device

All of the following stays in the app's own storage on your device and is never transmitted, including to the developer:

  • Handwriting in your notes
  • Recognized Python code and LaTeX formulas
  • Execution output and generated plot images
  • Note names, timestamps, and app settings such as panel position

Deleting the app deletes this data.

Handwriting recognition

Recognition runs entirely on your device. The model ships inside the app; no handwriting or image is sent to a server. No download or account is required.

Network use

The app itself makes no network connections. However, CodeNote exists to run Python code that you write, and your own code may access the network — for example, code using the requests library to call a web API. Such traffic goes directly between your device and the server you choose; the developer is not involved and receives nothing. One bundled example note calls a public API to demonstrate this.

Reporting a problem

The “Report a Problem” menu only acts when you send it yourself. A system mail or share sheet opens and you decide whether to send. Nothing is sent automatically. The attached diagnostic file contains your app/iOS version and device model, the current note's name, code and last output, and a recent activity log. You can review, edit, or cancel before sending.

Tracking and third parties

  • No advertising identifiers; no user tracking.
  • No analytics or advertising SDKs.
  • Nothing is collected, so nothing is shared or sold.

Children's privacy

No personal data is collected from users of any age.

Changes

If this policy changes, this page will be updated and the date above revised.
